Signal — Frontend

Overview

The frontend of Signal is a Next.js-based AI-native news interface that delivers personalized, credible, and interactive news experiences.

It acts as the primary user layer where users:

* consume AI-curated news
* interact with intelligent briefings
* watch short-form journalist videos (Signal Reels)
* access live news broadcasts
* engage with news through chat and discussions
